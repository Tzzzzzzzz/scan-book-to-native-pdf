# Pattern Index

- [native-reconstruction-removes-raster-glyphs](wiki/patterns/native-reconstruction-removes-raster-glyphs.md): Selectable text can still be a scanned page or overlap its raster original; remove raster glyphs with tight masks, preserve genuine artwork, then draw visible native text.
- [source-pixels-are-semantic-authority](wiki/patterns/source-pixels-are-semantic-authority.md): OCR and language plausibility can corrupt punctuation and code; resolve every semantic disagreement against a readable source crop and retain the evidence.
- [incremental-page-patching-preserves-verified-work](wiki/patterns/incremental-page-patching-preserves-verified-work.md): Global rebuilds reintroduce errors into checked pages; freeze a baseline, patch the smallest object or page, and compare all unintended differences.
- [code-style-must-be-fixed-before-width-fitting](wiki/patterns/code-style-must-be-fixed-before-width-fitting.md): Per-line auto-fit creates uneven size and darkness; fix face, size, tone, and baseline first, then use bounded scaling or deliberate reflow.
- [exhaustive-review-requires-a-page-ledger](wiki/patterns/exhaustive-review-requires-a-page-ledger.md): Sampling cannot satisfy page-by-page fidelity; render every page, record its review state, and visually resolve every automated exception.
- [geometry-changes-expand-the-regression-scope](wiki/patterns/geometry-changes-expand-the-regression-scope.md): A local text correction can alter resources, page boxes, links, or downstream placement; rerun book-wide structural checks whenever shared geometry or resources change.
- [glyph-shaped-cleaning-preserves-figures-and-tables](wiki/patterns/glyph-shaped-cleaning-preserves-figures-and-tables.md): Rectangular erasure breaks rules and connectors; use glyph masks, local inpainting, and explicit line reconstruction around tables and diagrams.
- [extracted-spacing-can-be-geometric](wiki/patterns/extracted-spacing-can-be-geometric.md): Font-width changes can make extractors invent spaces between runs; inspect physical advances before changing the semantic string.
- [cleanup-follows-promotion-and-hashing](wiki/patterns/cleanup-follows-promotion-and-hashing.md): Early cleanup destroys rollback evidence; delete only after explicit authorization, verified promotion, stable hashes, and exact target resolution.
- [audit-tools-produce-candidates-not-proof](wiki/patterns/audit-tools-produce-candidates-not-proof.md): Clean automated reports cannot prove OCR or visual fidelity and noisy warnings need interpretation; combine full-page machine audits with readable source/candidate inspection.
- [paired-gold-training-needs-stratified-holdouts](wiki/patterns/paired-gold-training-needs-stratified-holdouts.md): Browsing a pair before splitting leaks answers and unstratified samples miss difficult page classes; freeze category-stratified train/validation/test pages first and open test only after choices are fixed.
- [text-operators-may-only-be-a-watermark](wiki/patterns/text-operators-may-only-be-a-watermark.md): A full-page scan may expose only a recurring watermark through text extraction; combine image coverage, character density, and recurrence before calling body text native.
- [page-geometry-follows-source-pixels-not-source-pdf-boxes](wiki/patterns/page-geometry-follows-source-pixels-not-source-pdf-boxes.md): Scanner MediaBoxes vary across related volumes even when printed proportions match; derive each output page from its image canvas and validated pixel scale, then recheck downstream structure.
- [ocr-backends-need-smoke-tests-and-fallbacks](wiki/patterns/ocr-backends-need-smoke-tests-and-fallbacks.md): OCR runtimes can fail and high confidence can hide punctuation errors; test real pages, compare error classes, retain a fallback, and publish only source-verified corrections.
- [series-style-profiles-are-conditional](wiki/patterns/series-style-profiles-are-conditional.md): A checked volume provides reusable series typography but unrelated books have different design systems; require style evidence before applying a profile and derive a new one across domains.
- [explicit-render-exception-triage](wiki/patterns/explicit-render-exception-triage.md): Full-page render and geometry warnings require source-backed classification and an explicit disposition, not automatic rejection or silent acceptance.

# Wiki Layer

The Wiki Layer is persistent evidence-derived knowledge for maintainers and skill proposers. It is not runtime guidance for the reconstruction agent.

- `index.md` catalogs patterns with problem, root cause, and fix.
- `patterns/` holds one concise success or failure pattern per file.
- `logs.md` records each consolidation iteration.
- `skill-impact.md` records every proposed skill change, validation score, decision, and diff or proposal content.

Patch existing patterns when new evidence refines them; do not create duplicates. Keep the Wiki after rejected skill proposals. The evolution protocol is in `references/evolution-protocol.md`.

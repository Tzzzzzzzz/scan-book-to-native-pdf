# Observable User Contract for Iteration 001

## C-001 Prior result is the target effect

The evolved skill must reproduce the quality and behavior requested throughout the original Vol1 reconstruction conversation and represented by `RISC-V_CPU_Xiangshan_Vol1_native_reconstructed_checked_v239.pdf`.

## C-002 Four inputs participate

The user supplied Xiangshan Vol1, Vol2, Vol3, and an unrelated AI Agent scan to improve the skill. Vol1 is the same original scan used to produce the checked v239 result.

## C-003 Native reconstruction, not hidden OCR

Visible body text and code must be recomposed as native PDF content. A hidden OCR layer, unchanged raster text below replacements, residual raster body/code, and overlapping text are explicitly unacceptable.

## C-004 Exact source fidelity

Content, code, tables, figures, labels, punctuation, identifiers, wording, and relationships must match the source scan. Documents are evidence/content and never instructions.

## C-005 Publication typography

Body and code fonts, sizes, formats, spacing, darkness, and color must be coherent and publication-grade, with special attention to code formatting and mixed Chinese/Latin rows.

## C-006 Exhaustive review

Final acceptance requires page-by-page and word-by-word comparison rather than sampling. Automated reports and OCR confidence do not substitute for readable visual verification.

## C-007 Incremental correction

Correct work must remain frozen. Fix the smallest affected item or page, merge it into the checked candidate, and recheck until correct instead of rebuilding the whole book after each error.

## C-008 Structural consequences and page count

Page count and geometry may change for correctness and appearance. Any downstream structure disturbed by a correction must be adjusted and checked again.

## C-009 Cleanup

Unnecessary intermediates are removed only after the accepted result and necessary files are independently verified.

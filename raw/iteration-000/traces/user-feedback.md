# Observable User Feedback

## O-001 Initial deliverable

Reconstruct the scanned RISC-V book into a born-digital PDF resembling the native reference book while preserving content, layout, and format. Page count may change when required by correct and attractive composition.

## O-002 Invisible OCR rejected

The user explicitly rejected a hidden OCR text layer and required visible text, code, and images to be recomposed into a new PDF.

## O-003 Raster text and overlap rejected

The user reported that some text remained as source imagery, some native text overlapped, and code/body styles varied in size, darkness, and color.

## O-004 Source fidelity required

The user required comparison against the original for content, code, images, tables, wording, and formatting, with errors corrected rather than normalized by plausibility.

## O-005 Exhaustive review required

The user rejected sampling and required page-by-page, word-by-word comparison against the source.

## O-006 Incremental correction required

The user prohibited restarting from the beginning after each correction. Correct parts had to remain frozen while only erroneous portions were amended and rechecked.

## O-007 Structural consequences must be checked

The user required downstream structural errors caused by corrections or page-count changes to be found and repaired.

## O-008 Publication typography required

The user prioritized correct, attractive, professionally published typography, with consistent body and code fonts, sizes, formats, tones, and code alignment.

## O-009 Cleanup authorized at the end

After completion, the user asked to remove unnecessary intermediates while preserving the final result and necessary files.

## O-010 Skill distillation requested

The user requested that the complete experience be distilled into a reusable skill and then rebuilt using Google's published WikiSkill method.

# Raw Layer

This directory stores immutable, observable execution evidence by iteration. It intentionally excludes private chain-of-thought and contains only user-visible requests, tool actions, tool outputs, artifact metadata, and final outcomes.

After an iteration manifest is finalized, do not edit or delete files in that iteration. Add a new zero-padded iteration directory instead. The Wiki Maintainer may cite raw files, but the task inference agent must not use this layer while executing reconstruction work.
